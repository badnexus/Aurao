Frequently Asked Questions (FAQ)

Quick answers for everyday users and AI search engines.

Kurze Antworten auf die wichtigsten Fragen.

What is Aurao?

Aurao is a free, open-source desktop application for Windows, macOS, and Linux that lets non-technical users run autonomous AI agents (Claude Code, OpenAI Codex CLI, and Google Antigravity) through a safe visual chat and file workspace interface without touching the command line.

Can Aurao accidentally delete or overwrite my local files?

No. By default, Aurao operates in Safe Changes mode. Whenever the assistant wants to create, edit, or delete a file, it displays an interactive Approval Card explaining the exact change. Nothing happens unless you click Approve.

Do I need to know how to code or use a terminal?

Not at all. Aurao includes a Plain-Language Persona that eliminates developer jargon (no "repositories", "commits", "CWD", or "stdout") and communicates in familiar desktop concepts like folders, documents, and 1-click approvals.

How does Aurao connect to AI models?

On first launch, Aurao automatically detects whether you have Claude Code (claude), OpenAI Codex CLI (codex), or Google Antigravity (agy) installed, and includes a built-in Settings & Health Check modal (⚙️) to configure your preferred model in seconds.
